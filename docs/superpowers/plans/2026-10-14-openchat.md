# OpenChat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A localhost-only, single-user Claude.ai-style chat app that talks to any model the user adds from OpenRouter, with branching (regenerate/edit) history, search, cost tracking, and manual personalization/memory.

**Architecture:** A Node/TypeScript server (Hono + better-sqlite3) owns the API key, the SQLite database, and all OpenRouter traffic, and streams replies to the browser as server-sent events. A React + Vite SPA renders the sidebar, chat view, Model Library, and Settings, using hash routing. Shared TypeScript types and the SSE parser live in `shared/` and are used by both sides.

**Tech Stack:** Node 24, TypeScript 5 (strict, ESM), Hono 4 + @hono/node-server 1, better-sqlite3 12 (FTS5), React 19, Vite 7, react-markdown 10 + remark-gfm 4 + rehype-highlight 7, Vitest 3, tsx 4, concurrently 9.

**Spec:** `docs/superpowers/specs/2026-10-14-openchat-design.md`

## Global Constraints

- Server binds to `127.0.0.1` only; port `3000` (override with `PORT`).
- The OpenRouter API key is never sent to the browser — only `apiKeyMasked`, `hasApiKey`, `apiKeySource`.
- API key precedence: Settings value > `OPENROUTER_API_KEY` in `.env`.
- Database file: `data/openchat.db` (override with `OPENCHAT_DB`); `data/`, `dist/`, `.env`, `node_modules/` are gitignored.
- New chats are titled exactly `New chat` until auto-titled or renamed.
- All costs are USD as reported by OpenRouter (`usage: { include: true }`); never computed client-side.
- Single `package.json` at the repo root, `"type": "module"`, TypeScript `strict: true`.
- Messages passed to tree functions are always ordered oldest-first (`ORDER BY created_at, seq`).
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Spec Adjustments (decided while planning)

- **Send** (`POST /api/chats/:id/messages`) takes `{content, modelId}`; the server attaches the new user message to the chat's `active_leaf_id` instead of trusting a client `parentId` (matches the spec's "new messages always attach to the active leaf").
- **Regenerate** takes `{parentId, modelId}` where `parentId` is the *user* message to reply to. The client passes the assistant's `parentId` for a normal regenerate, or the last user message id for Retry after a failure. A failed regenerate leaves the previously active reply visible.
- **Model library** mutations identify models via JSON body / `?id=` query (`PATCH /api/models`, `DELETE /api/models?id=`) because OpenRouter ids contain `/` and `:`.
- **New chat** is created lazily on the first send, so empty chats never appear in the sidebar.
- **Search result click** selects that message's branch (`PATCH selectMessageId`) before opening the chat, so the hit is visible.
- **Chat header title** comes from the sidebar chat list so renames/auto-titles show immediately.

## Review Focus

1. **Search input containing FTS5 syntax** (`"`, `*`, `(`, `-x`, `AND`, `c++`, lone punctuation) → behaves like plain-word search or returns `[]`; never a 500. *(Task 8 test: "search never errors on FTS syntax characters")*
2. **Stop / tab close mid-response** → partial text saved with `status='stopped'` and becomes the active leaf; stop before the first token saves only the user message. *(Task 9 tests: "client abort mid-stream saves partial as stopped", "error before any output…")*
3. **Provider error after partial output** (OpenRouter sends an `error` chunk mid-stream) → partial kept as stopped, `error` event carries it, Retry available. *(Task 5 test "throws on a mid-stream error chunk…", Task 9 test "mid-stream error saves partial…")*
4. **Model ids with `/`, `:` and `~`** (e.g. `openai/gpt-4o:free`, `~anthropic/claude`) → add, rename, set default, remove all work. *(Task 7 test: "handles ids with slashes, colons and tildes")*
5. **Title generation fails or returns junk** → the reply still completes and is saved; title stays `New chat`. *(Task 9 test: "title failure does not affect the reply"; Task 9 `cleanTitle` unit test)*

```ts
export function streamOf(...chunks: string[]): ReadableStream<Uint8Array> {
  const enc = new TextEncoder();
  return new ReadableStream({
    start(controller) {
      for (const chunk of chunks) controller.enqueue(enc.encode(chunk));
      controller.close();
    },
  });
}

export async function collect<T>(iterable: AsyncIterable<T>): Promise<T[]> {
  const out: T[] = [];
  for await (const item of iterable) out.push(item);
  return out;
}
```

```ts
export interface SSEEvent {
  event: string;
  data: string;
}

/** Parses a text/event-stream body into events. Comment lines (": ...") and id/retry fields are ignored. */
export async function* parseSSE(body: ReadableStream<Uint8Array>): AsyncGenerator<SSEEvent> {
  const reader = body.pipeThrough(new TextDecoderStream()).getReader();
  let buffer = '';
  try {
    while (true) {
      const { value, done } = await reader.read();
      if (done) break;
      buffer += value;
      let match: RegExpExecArray | null;
      while ((match = /\r?\n\r?\n/.exec(buffer))) {
        const block = buffer.slice(0, match.index);
        buffer = buffer.slice(match.index + match[0].length);
        const event = parseBlock(block);
        if (event) yield event;
      }
    }
    const event = parseBlock(buffer);
    if (event) yield event;
  } finally {
    await reader.cancel().catch(() => {});
  }
}

function parseBlock(block: string): SSEEvent | null {
  let event = 'message';
  const data: string[] = [];
  for (const line of block.split(/\r?\n/)) {
    if (!line || line.startsWith(':')) continue;
    const colon = line.indexOf(':');
    const field = colon === -1 ? line : line.slice(0, colon);
    let value = colon === -1 ? '' : line.slice(colon + 1);
    if (value.startsWith(' ')) value = value.slice(1);
    if (field === 'event') event = value;
    else if (field === 'data') data.push(value);
  }
  return data.length ? { event, data: data.join('\n') } : null;
}
```

- [ ] **Step 4: Implement `server/src/db.ts`**

`seq` is an INTEGER PRIMARY KEY so FTS5's external-content rowid stays stable (a plain implicit rowid can change on VACUUM).

```ts
import Database from 'better-sqlite3';
import { randomUUID } from 'node:crypto';
import { mkdirSync } from 'node:fs';
import { dirname } from 'node:path';

export type DB = Database.Database;

const SCHEMA = `
CREATE TABLE IF NOT EXISTS settings (key TEXT PRIMARY KEY, value TEXT NOT NULL);

CREATE TABLE IF NOT EXISTS models (
  id TEXT PRIMARY KEY,
  display_name TEXT NOT NULL,
  context_length INTEGER,
  prompt_price REAL,
  completion_price REAL,
  added_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS memories (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  content TEXT NOT NULL,
  enabled INTEGER NOT NULL DEFAULT 1,
  created_at INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS chats (
  id TEXT PRIMARY KEY,
  title TEXT NOT NULL,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL,
  active_leaf_id TEXT
);

CREATE TABLE IF NOT EXISTS messages (
  seq INTEGER PRIMARY KEY AUTOINCREMENT,
  id TEXT NOT NULL UNIQUE,
  chat_id TEXT NOT NULL REFERENCES chats(id) ON DELETE CASCADE,
  parent_id TEXT REFERENCES messages(id) ON DELETE CASCADE,
  role TEXT NOT NULL CHECK (role IN ('user', 'assistant')),
  content TEXT NOT NULL,
  model_id TEXT,
  prompt_tokens INTEGER,
  completion_tokens INTEGER,
  cost REAL,
  status TEXT NOT NULL DEFAULT 'complete',
  created_at INTEGER NOT NULL
);
CREATE INDEX IF NOT EXISTS messages_chat ON messages(chat_id, created_at);

CREATE VIRTUAL TABLE IF NOT EXISTS messages_fts USING fts5(content, content='messages', content_rowid='seq');
CREATE TRIGGER IF NOT EXISTS messages_ai AFTER INSERT ON messages BEGIN
  INSERT INTO messages_fts(rowid, content) VALUES (new.seq, new.content);
END;
CREATE TRIGGER IF NOT EXISTS messages_ad AFTER DELETE ON messages BEGIN
  INSERT INTO messages_fts(messages_fts, rowid, content) VALUES ('delete', old.seq, old.content);
END;
CREATE TRIGGER IF NOT EXISTS messages_au AFTER UPDATE OF content ON messages BEGIN
  INSERT INTO messages_fts(messages_fts, rowid, content) VALUES ('delete', old.seq, old.content);
  INSERT INTO messages_fts(rowid, content) VALUES (new.seq, new.content);
END;

CREATE TABLE IF NOT EXISTS model_catalog_cache (
  id INTEGER PRIMARY KEY CHECK (id = 1),
  fetched_at INTEGER NOT NULL,
  json TEXT NOT NULL
);
`;

export function openDb(file: string): DB {
  if (file !== ':memory:') mkdirSync(dirname(file), { recursive: true });
  const db = new Database(file);
  db.pragma('journal_mode = WAL');
  db.pragma('foreign_keys = ON');
  db.exec(SCHEMA);
  return db;
}

export const newId = (): string => randomUUID();

let last = 0;
/** Millisecond timestamp, strictly increasing within this process so ordering never ties. */
export function now(): number {
  const t = Date.now();
  last = t > last ? t : last + 1;
  return last;
}
```

```ts
import type { Message, PathMessage } from '../../shared/types';

// All functions expect `messages` ordered oldest first (as returned by getChatMessages).

export function activePath(messages: Message[], leafId: string | null): Message[] {
  const byId = new Map(messages.map((m) => [m.id, m]));
  const path: Message[] = [];
  let cur = leafId ? byId.get(leafId) : undefined;
  while (cur) {
    path.push(cur);
    cur = cur.parentId ? byId.get(cur.parentId) : undefined;
  }
  return path.reverse();
}

export function childrenOf(messages: Message[], parentId: string | null): Message[] {
  return messages.filter((m) => m.parentId === parentId);
}

export function newestLeafFrom(messages: Message[], messageId: string): string {
  let id = messageId;
  for (;;) {
    const kids = childrenOf(messages, id);
    if (kids.length === 0) return id;
    id = kids[kids.length - 1].id;
  }
}

export function withSiblings(messages: Message[], path: Message[]): PathMessage[] {
  return path.map((m) => {
    const siblingIds = childrenOf(messages, m.parentId).map((s) => s.id);
    return { ...m, siblingIds, siblingIndex: siblingIds.indexOf(m.id) };
  });
}
```

```ts
import type { Message } from '../../shared/types';

export interface Persona {
  aboutMe: string;
  customInstructions: string;
  memories: string[];
}

export interface ChatMessage {
  role: 'system' | 'user' | 'assistant';
  content: string;
}

export function buildSystemPrompt(p: Persona): string | null {
  const sections: string[] = [];
  if (p.aboutMe.trim()) sections.push(`About the user:\n${p.aboutMe.trim()}`);
  if (p.customInstructions.trim()) sections.push(`Instructions:\n${p.customInstructions.trim()}`);
  const memories = p.memories.map((m) => m.trim()).filter(Boolean);
  if (memories.length) sections.push(`Things to remember about the user:\n${memories.map((m) => `- ${m}`).join('\n')}`);
  return sections.length ? sections.join('\n\n') : null;
}

export function buildMessages(p: Persona, path: Pick<Message, 'role' | 'content'>[]): ChatMessage[] {
  const system = buildSystemPrompt(p);
  const messages: ChatMessage[] = path.map((m) => ({ role: m.role, content: m.content }));
  return system ? [{ role: 'system', content: system }, ...messages] : messages;
}
```

```ts
import type { DB } from './db';
import { HttpError } from './http';
import type { Persona } from './prompt';
import type { SettingsUpdate, SettingsView, Theme } from '../../shared/types';

const DEFAULTS = {
  api_key: '',
  about_me: '',
  custom_instructions: '',
  theme: 'system',
  default_model_id: '',
  title_model_id: '',
};
export type SettingKey = keyof typeof DEFAULTS;
export type Env = Record<string, string | undefined>;

const THEMES: Theme[] = ['light', 'dark', 'system'];

const UPDATE_KEYS: Record<keyof SettingsUpdate, SettingKey> = {
  apiKey: 'api_key',
  aboutMe: 'about_me',
  customInstructions: 'custom_instructions',
  theme: 'theme',
  defaultModelId: 'default_model_id',
  titleModelId: 'title_model_id',
};

export function getSetting(db: DB, key: SettingKey): string {
  const row = db.prepare('SELECT value FROM settings WHERE key = ?').get(key) as { value: string } | undefined;
  return row?.value ?? DEFAULTS[key];
}

export function setSetting(db: DB, key: SettingKey, value: string): void {
  db.prepare('INSERT INTO settings (key, value) VALUES (?, ?) ON CONFLICT(key) DO UPDATE SET value = excluded.value').run(key, value);
}

export function resolveApiKey(db: DB, env: Env): { key: string; source: 'settings' | 'env' | 'none' } {
  const stored = getSetting(db, 'api_key');
  if (stored) return { key: stored, source: 'settings' };
  const fromEnv = env.OPENROUTER_API_KEY?.trim();
  if (fromEnv) return { key: fromEnv, source: 'env' };
  return { key: '', source: 'none' };
}

export function maskKey(key: string): string {
  if (!key) return '';
  if (key.length <= 10) return '••••';
  return `${key.slice(0, 6)}…${key.slice(-4)}`;
}

export function getSettingsView(db: DB, env: Env): SettingsView {
  const { key, source } = resolveApiKey(db, env);
  return {
    hasApiKey: Boolean(key),
    apiKeySource: source,
    apiKeyMasked: maskKey(key),
    aboutMe: getSetting(db, 'about_me'),
    customInstructions: getSetting(db, 'custom_instructions'),
    theme: getSetting(db, 'theme') as Theme,
    defaultModelId: getSetting(db, 'default_model_id'),
    titleModelId: getSetting(db, 'title_model_id'),
  };
}

export function updateSettings(db: DB, update: SettingsUpdate): void {
  if (update.theme !== undefined && !THEMES.includes(update.theme)) {
    throw new HttpError(400, 'Theme must be light, dark, or system.');
  }
  for (const [field, key] of Object.entries(UPDATE_KEYS) as [keyof SettingsUpdate, SettingKey][]) {
    const value = update[field];
    if (value === undefined) continue;
    if (typeof value !== 'string') throw new HttpError(400, `${field} must be a string.`);
    setSetting(db, key, field === 'apiKey' ? value.trim() : value);
  }
}

export function getPersona(db: DB): Persona {
  const rows = db.prepare('SELECT content FROM memories WHERE enabled = 1 ORDER BY created_at, id').all() as { content: string }[];
  return {
    aboutMe: getSetting(db, 'about_me'),
    customInstructions: getSetting(db, 'custom_instructions'),
    memories: rows.map((r) => r.content),
  };
}
```

```ts
import { parseSSE } from '../../shared/sse';
import type { CatalogModel } from '../../shared/types';
import type { ChatMessage } from './prompt';

export const OPENROUTER_BASE = 'https://openrouter.ai/api/v1';

export class OpenRouterError extends Error {
  constructor(message: string, public status: number) {
    super(message);
    this.name = 'OpenRouterError';
  }
}

const STATUS_MESSAGES: Record<number, string> = {
  401: 'OpenRouter rejected the API key. Check it in Settings.',
  402: 'Your OpenRouter account is out of credits.',
  404: 'That model is not available on OpenRouter.',
  408: 'The request to OpenRouter timed out.',
  429: 'Rate limited by OpenRouter or the model provider. Wait a moment and retry.',
  502: 'The model provider returned an error.',
  503: 'No provider is currently available for this model.',
};

export function friendlyError(status: number, detail?: string): string {
  const base = STATUS_MESSAGES[status] ?? `OpenRouter error (${status}).`;
  return detail ? `${base} (${detail})` : base;
}

function extractDetail(body: string): string | undefined {
  try {
    const message = JSON.parse(body)?.error?.message;
    return typeof message === 'string' && message ? message : undefined;
  } catch {
    return undefined;
  }
}

const toPrice = (value: unknown): number | null => {
  if (value === undefined || value === null || value === '') return null;
  const n = Number(value);
  return Number.isNaN(n) ? null : n;
};

export interface Usage {
  promptTokens: number | null;
  completionTokens: number | null;
  cost: number | null;
}

export type StreamEvent = { type: 'delta'; text: string } | { type: 'usage'; usage: Usage };

export interface OpenRouterClient {
  listModels(): Promise<CatalogModel[]>;
  checkKey(apiKey: string): Promise<void>;
  complete(o: { apiKey: string; model: string; messages: ChatMessage[]; maxTokens?: number }): Promise<string>;
  streamChat(o: { apiKey: string; model: string; messages: ChatMessage[]; signal?: AbortSignal }): AsyncGenerator<StreamEvent>;
}

export function createOpenRouterClient(fetchImpl: typeof fetch = fetch, base = OPENROUTER_BASE): OpenRouterClient {
  async function request(path: string, init: RequestInit & { apiKey?: string } = {}): Promise<Response> {
    const { apiKey, ...rest } = init;
    const headers: Record<string, string> = {
      'Content-Type': 'application/json',
      'HTTP-Referer': 'http://localhost:3000',
      'X-Title': 'OpenChat',
    };
    if (apiKey) headers.Authorization = `Bearer ${apiKey}`;
    let res: Response;
    try {
      res = await fetchImpl(`${base}${path}`, { ...rest, headers });
    } catch (err) {
      if ((err as Error).name === 'AbortError') throw err;
      throw new OpenRouterError('Could not reach OpenRouter. Check your internet connection.', 0);
    }
    if (!res.ok) {
      const body = await res.text().catch(() => '');
      throw new OpenRouterError(friendlyError(res.status, extractDetail(body)), res.status);
    }
    return res;
  }

  return {
    async listModels() {
      const res = await request('/models');
      const json = (await res.json()) as { data?: any[] };
      return (json.data ?? []).map((m) => ({
        id: String(m.id),
        name: String(m.name ?? m.id),
        contextLength: typeof m.context_length === 'number' ? m.context_length : null,
        promptPrice: toPrice(m.pricing?.prompt),
        completionPrice: toPrice(m.pricing?.completion),
      }));
    },

    async checkKey(apiKey) {
      await request('/key', { apiKey });
    },

    async complete({ apiKey, model, messages, maxTokens }) {
      const res = await request('/chat/completions', {
        method: 'POST',
        apiKey,
        body: JSON.stringify({ model, messages, max_tokens: maxTokens }),
      });
      const json = (await res.json()) as any;
      return String(json.choices?.[0]?.message?.content ?? '');
    },

    async *streamChat({ apiKey, model, messages, signal }) {
      const res = await request('/chat/completions', {
        method: 'POST',
        apiKey,
        signal,
        body: JSON.stringify({ model, messages, stream: true, usage: { include: true } }),
      });
      if (!res.body) throw new OpenRouterError('Empty response from OpenRouter.', 502);
      for await (const { data } of parseSSE(res.body)) {
        if (data === '[DONE]') return;
        let chunk: any;
        try {
          chunk = JSON.parse(data);
        } catch {
          continue;
        }
        if (chunk.error) {
          const status = Number(chunk.error.code) || 502;
          throw new OpenRouterError(friendlyError(status, chunk.error.message), status);
        }
        const text = chunk.choices?.[0]?.delta?.content;
        if (text) yield { type: 'delta', text };
        if (chunk.usage) {
          yield {
            type: 'usage',
            usage: {
              promptTokens: chunk.usage.prompt_tokens ?? null,
              completionTokens: chunk.usage.completion_tokens ?? null,
              cost: typeof chunk.usage.cost === 'number' ? chunk.usage.cost : null,
            },
          };
        }
      }
    },
  };
}
```

```ts
import { Hono } from 'hono';
import type { Deps } from '../app';
import type { DB } from '../db';
import { now } from '../db';
import { HttpError, readJson } from '../http';
import type { Memory } from '../../../shared/types';

interface MemoryRow { id: number; content: string; enabled: number; created_at: number }

const toMemory = (r: MemoryRow): Memory => ({ id: r.id, content: r.content, enabled: r.enabled === 1, createdAt: r.created_at });

function requireMemory(db: DB, id: number): MemoryRow {
  const row = db.prepare('SELECT * FROM memories WHERE id = ?').get(id) as MemoryRow | undefined;
  if (!row) throw new HttpError(404, 'Memory not found.');
  return row;
}

function cleanContent(content: unknown): string {
  const text = typeof content === 'string' ? content.trim() : '';
  if (!text) throw new HttpError(400, 'Memory cannot be empty.');
  return text;
}

export function memoryRoutes({ db }: Deps): Hono {
  const r = new Hono();

  r.get('/', (c) => {
    const rows = db.prepare('SELECT * FROM memories ORDER BY created_at, id').all() as MemoryRow[];
    return c.json(rows.map(toMemory));
  });

  r.post('/', async (c) => {
    const { content } = await readJson<{ content?: string }>(c);
    const info = db.prepare('INSERT INTO memories (content, enabled, created_at) VALUES (?, 1, ?)').run(cleanContent(content), now());
    return c.json(toMemory(requireMemory(db, Number(info.lastInsertRowid))), 201);
  });

  r.patch('/:id', async (c) => {
    const id = Number(c.req.param('id'));
    requireMemory(db, id);
    const body = await readJson<{ content?: string; enabled?: boolean }>(c);
    if (body.content !== undefined) db.prepare('UPDATE memories SET content = ? WHERE id = ?').run(cleanContent(body.content), id);
    if (body.enabled !== undefined) db.prepare('UPDATE memories SET enabled = ? WHERE id = ?').run(body.enabled ? 1 : 0, id);
    return c.json(toMemory(requireMemory(db, id)));
  });

  r.delete('/:id', (c) => {
    const id = Number(c.req.param('id'));
    requireMemory(db, id);
    db.prepare('DELETE FROM memories WHERE id = ?').run(id);
    return c.json({ ok: true });
  });

  return r;
}
```

```ts
import type { DB } from './db';
import { HttpError } from './http';
import type { OpenRouterClient } from './openrouter';
import type { CatalogModel, CatalogResponse } from '../../shared/types';

export const CATALOG_TTL_MS = 24 * 60 * 60 * 1000;

export async function getCatalog(db: DB, openrouter: OpenRouterClient, refresh: boolean): Promise<CatalogResponse> {
  const cached = db.prepare('SELECT fetched_at, json FROM model_catalog_cache WHERE id = 1').get() as
    | { fetched_at: number; json: string }
    | undefined;
  if (cached && !refresh && Date.now() - cached.fetched_at < CATALOG_TTL_MS) {
    return { models: JSON.parse(cached.json), fetchedAt: cached.fetched_at, stale: false };
  }
  try {
    const models = (await openrouter.listModels()).sort((a, b) => a.name.localeCompare(b.name));
    const fetchedAt = Date.now();
    db.prepare(
      'INSERT INTO model_catalog_cache (id, fetched_at, json) VALUES (1, ?, ?) ON CONFLICT(id) DO UPDATE SET fetched_at = excluded.fetched_at, json = excluded.json',
    ).run(fetchedAt, JSON.stringify(models));
    return { models, fetchedAt, stale: false };
  } catch (err) {
    if (cached) return { models: JSON.parse(cached.json) as CatalogModel[], fetchedAt: cached.fetched_at, stale: true };
```

```ts
  db.prepare(
    'INSERT OR IGNORE INTO models (id, display_name, context_length, prompt_price, completion_price, added_at) VALUES (?, ?, ?, ?, ?, ?)',
```

```ts
import { addModel, listLibrary, removeModel, renameModel, requireLibraryModel, setDefaultModel } from '../library';

const requireId = (id: unknown): string => {
  const value = typeof id === 'string' ? id.trim() : '';
  if (!value) throw new HttpError(400, 'Model id is required.');
  return value;
};

export function modelRoutes({ db, openrouter }: Deps): Hono {
  const r = new Hono();

  r.get('/', (c) => c.json(listLibrary(db)));

  r.get('/catalog', async (c) => c.json(await getCatalog(db, openrouter, c.req.query('refresh') === '1')));

  r.post('/', async (c) => {
    const id = requireId((await readJson<{ id?: string }>(c)).id);
    const catalog = await getCatalog(db, openrouter, false).catch(() => null);
    const meta = catalog?.models.find((m) => m.id === id) ?? { id, name: id, contextLength: null, promptPrice: null, completionPrice: null };
    addModel(db, meta);
    return c.json(listLibrary(db), 201);
  });

  r.patch('/', async (c) => {
    const body = await readJson<{ id?: string; displayName?: string; isDefault?: boolean }>(c);
    const id = requireId(body.id);
    requireLibraryModel(db, id);
    const name = body.displayName?.trim();
    if (name) renameModel(db, id, name);
    if (body.isDefault) setDefaultModel(db, id);
    return c.json(listLibrary(db));
  });

  r.delete('/', (c) => {
    removeModel(db, requireId(c.req.query('id')));
    return c.json(listLibrary(db));
  });

  return r;
}
```

```ts
import type { DB } from './db';
import type { SearchHit } from '../../shared/types';

export function toFtsQuery(input: string): string | null {
  const terms = input.replace(/[^\p{L}\p{N}]+/gu, ' ').trim().split(/\s+/).filter(Boolean);
  if (terms.length === 0) return null;
  return terms.map((t) => `"${t}"*`).join(' ');
}

export function searchMessages(db: DB, q: string): SearchHit[] {
  const query = toFtsQuery(q);
  if (!query) return [];
  return db.prepare(
    `SELECT m.id AS messageId, m.chat_id AS chatId, c.title AS chatTitle,
            snippet(messages_fts, 0, '«', '»', '…', 12) AS snippet
     FROM messages_fts
     JOIN messages m ON m.seq = messages_fts.rowid
     JOIN chats c ON c.id = m.chat_id
     WHERE messages_fts MATCH ?
     ORDER BY rank
     LIMIT 30`,
  ).all(query) as SearchHit[];
}
```

```ts
  const firstLine = raw.trim().split('\n')[0] ?? '';

    .replace(/^["'`*#\s]+/, '')
    .replace(/["'`*.\s]+$/, '')

/** Titles a chat after its first reply. Never throws; returns the new title or null. */
export async function maybeGenerateTitle(deps: Deps, chatId: string, apiKey: string, fallbackModel: string): Promise<string | null> {
  const { db, openrouter } = deps;
  const chat = getChatRow(db, chatId);
  if (!chat || chat.title !== DEFAULT_TITLE) return null;
  const all = getChatMessages(db, chatId);
  if (all.filter((m) => m.role === 'assistant').length !== 1) return null;
  const transcript = activePath(all, chat.active_leaf_id)
    .map((m) => `${m.role}: ${m.content}`)
    .join('\n\n')
    .slice(0, 4000);
  try {
    const raw = await openrouter.complete({
      apiKey,
      model: getSetting(db, 'title_model_id') || fallbackModel,
      maxTokens: 30,
      messages: [
        { role: 'system', content: 'Write a short title (at most 6 words) for this conversation. Reply with the title only.' },
        { role: 'user', content: transcript },
      ],
    });
    const title = cleanTitle(raw);
    if (!title) return null;
    renameChat(db, chatId, title);
    return title;
  } catch {
    return null;
  }
}
```

```ts
import type { Context } from 'hono';
import { streamSSE } from 'hono/streaming';
import type { Deps } from './app';
import { newId } from './db';
import { setActiveLeaf, touchChat } from './chats';
import { getChatMessages, insertMessage } from './messages';
import { OpenRouterError, type Usage } from './openrouter';
import { buildMessages } from './prompt';
import { getPersona, resolveApiKey } from './settings';
import { maybeGenerateTitle } from './title';
import { activePath } from './tree';
import type { Message, MessageStatus, StreamDone, StreamError, StreamStart, StreamTitle } from '../../shared/types';

interface ReplyOptions {
  chatId: string;
  /** The user message being replied to. */
  parentId: string;
  modelId: string;
  /** Set when this request created a new user message. */
  userMessageId: string | null;
}

/**
 * Streams an assistant reply to `parentId` as SSE: start → delta* → done | error, then optional title.
 * The reply is saved on completion; partial text is saved as 'stopped' on error or client disconnect.
 */
export function streamReply(c: Context, deps: Deps, o: ReplyOptions): Response {
  const { db, openrouter, env } = deps;
  const messages = buildMessages(getPersona(db), activePath(getChatMessages(db, o.chatId), o.parentId));
  const { key } = resolveApiKey(db, env);
  const assistantId = newId();
  const abort = new AbortController();
  c.req.raw.signal.addEventListener('abort', () => abort.abort());

  return streamSSE(c, async (stream) => {
    stream.onAbort(() => abort.abort());
    const send = (event: string, data: unknown) => stream.writeSSE({ event, data: JSON.stringify(data) });

    let text = '';
    let usage: Usage | null = null;
    const save = (status: MessageStatus): Message => {
      const message = insertMessage(db, {
        id: assistantId,
        chatId: o.chatId,
        parentId: o.parentId,
        role: 'assistant',
        content: text,
        modelId: o.modelId,
        promptTokens: usage?.promptTokens ?? null,
        completionTokens: usage?.completionTokens ?? null,
        cost: usage?.cost ?? null,
        status,
      });
      setActiveLeaf(db, o.chatId, message.id);
      touchChat(db, o.chatId);
      return message;
    };

    await send('start', { userMessageId: o.userMessageId, assistantMessageId: assistantId } satisfies StreamStart);
    try {
      if (!key) throw new OpenRouterError('No OpenRouter API key set. Add one in Settings.', 401);
      for await (const event of openrouter.streamChat({ apiKey: key, model: o.modelId, messages, signal: abort.signal })) {
        if (event.type === 'delta') {
          text += event.text;
          await send('delta', { text: event.text });
        } else {
          usage = event.usage;
        }
      }
      const message = save('complete');
      await send('done', { message } satisfies StreamDone);
      const title = await maybeGenerateTitle(deps, o.chatId, key, o.modelId);
      if (title) await send('title', { title } satisfies StreamTitle);
    } catch (err) {
      const partial = text ? save('stopped') : null;
      if (abort.signal.aborted) return; // client went away; nothing to send
      const message = err instanceof OpenRouterError ? err.message : 'Something went wrong while generating the reply.';
      if (!(err instanceof OpenRouterError)) console.error(err);
      await send('error', { message, partial } satisfies StreamError);
    }
  });
}
```

```ts
import { Hono } from 'hono';
import type { Deps } from '../app';
import { HttpError, readJson } from '../http';
import { requireChat, setActiveLeaf, touchChat } from '../chats';
import { getMessage, insertMessage } from '../messages';

import type { DB } from '../db';
import type { Message } from '../../../shared/types';

const requireText = (value: unknown, error: string): string => {
  if (typeof value !== 'string' || !value.trim()) throw new HttpError(400, error);
  return value;
};

function requireUserMessage(db: DB, chatId: string, id: unknown): Message {
  const message = typeof id === 'string' ? getMessage(db, id) : undefined;
  if (!message || message.chatId !== chatId || message.role !== 'user') {
    throw new HttpError(400, 'That message is not a user message in this chat.');
  }
  return message;
}

export function generationRoutes(deps: Deps): Hono {
  const { db } = deps;
  const r = new Hono();

  r.post('/:id/messages', async (c) => {
    const chatId = c.req.param('id');
    const chat = requireChat(db, chatId);
    const body = await readJson<{ content?: string; modelId?: string }>(c);
    const content = requireText(body.content, 'Message is empty.');
    const modelId = requireText(body.modelId, 'Pick a model first.');
    const user = insertMessage(db, { chatId, parentId: chat.active_leaf_id, role: 'user', content });
    setActiveLeaf(db, chatId, user.id);
    touchChat(db, chatId);
    return streamReply(c, deps, { chatId, parentId: user.id, modelId, userMessageId: user.id });
  });

  r.post('/:id/regenerate', async (c) => {
    const chatId = c.req.param('id');
    requireChat(db, chatId);
    const body = await readJson<{ parentId?: string; modelId?: string }>(c);
    const parent = requireUserMessage(db, chatId, body.parentId);
    const modelId = requireText(body.modelId, 'Pick a model first.');
    return streamReply(c, deps, { chatId, parentId: parent.id, modelId, userMessageId: null });
  });

  r.post('/:id/edit', async (c) => {
    const chatId = c.req.param('id');
    requireChat(db, chatId);
    const body = await readJson<{ messageId?: string; content?: string; modelId?: string }>(c);
    const original = requireUserMessage(db, chatId, body.messageId);
    const content = requireText(body.content, 'Message is empty.');
    const modelId = requireText(body.modelId, 'Pick a model first.');
    const user = insertMessage(db, { chatId, parentId: original.parentId, role: 'user', content });
    setActiveLeaf(db, chatId, user.id);
    touchChat(db, chatId);
    return streamReply(c, deps, { chatId, parentId: user.id, modelId, userMessageId: user.id });
  });
```

```ts
export function formatCost(usd: number | null): string {
  if (usd === null) return '';
  if (usd === 0) return '$0';
  if (usd < 0.0001) return '<$0.0001';
  if (usd < 0.01) return `$${usd.toFixed(4)}`;
  return `$${usd.toFixed(2)}`;
}

export const formatTokens = (n: number): string => n.toLocaleString('en-US');

export function formatPricePerM(perToken: number | null): string {
  if (perToken === null) return '—';
  if (perToken < 0) return 'varies';
  if (perToken === 0) return 'free';
  return `$${(perToken * 1_000_000).toFixed(2)}/M`;
}

export function formatContext(n: number | null): string {
  if (!n) return '';
  if (n >= 1_000_000) return `${+(n / 1_000_000).toFixed(1)}M`;
  if (n >= 1000) return `${Math.round(n / 1000)}K`;
  return String(n);
}

export type DateGroup = 'Today' | 'Yesterday' | 'Previous 7 days' | 'Older';

export function groupByDate<T extends { updatedAt: number }>(items: T[], now = new Date()): { label: DateGroup; items: T[] }[] {
  const DAY = 86_400_000;
  const today = new Date(now.getFullYear(), now.getMonth(), now.getDate()).getTime();
  const groups: { label: DateGroup; items: T[] }[] = [
    { label: 'Today', items: [] },
    { label: 'Yesterday', items: [] },
    { label: 'Previous 7 days', items: [] },
    { label: 'Older', items: [] },
  ];
  for (const item of items) {
    const t = item.updatedAt;
    const index = t >= today ? 0 : t >= today - DAY ? 1 : t >= today - 7 * DAY ? 2 : 3;
    groups[index].items.push(item);
  }
  return groups.filter((g) => g.items.length > 0);
}

/** Splits a search snippet whose matches are wrapped in « » into plain and highlighted parts. */
export function splitSnippet(snippet: string): { text: string; hit: boolean }[] {
  return snippet
    .split(/(«[^»]*»)/)
    .filter(Boolean)
    .map((part) => (part.startsWith('«') ? { text: part.slice(1, -1), hit: true } : { text: part, hit: false }));
}
```

```ts
import { useMemo, useSyncExternalStore } from 'react';

export type Route = { page: 'chat'; chatId: string | null } | { page: 'models' } | { page: 'settings' };

export function parseHash(hash: string): Route {
  const parts = hash.replace(/^#\/?/, '').split('/');
  if (parts[0] === 'models') return { page: 'models' };
  if (parts[0] === 'settings') return { page: 'settings' };
  if (parts[0] === 'chat' && parts[1]) return { page: 'chat', chatId: decodeURIComponent(parts[1]) };
  return { page: 'chat', chatId: null };
}

const subscribe = (onChange: () => void) => {
  window.addEventListener('hashchange', onChange);
  return () => window.removeEventListener('hashchange', onChange);
};

export function useRoute(): Route {
  const hash = useSyncExternalStore(subscribe, () => window.location.hash);
  return useMemo(() => parseHash(hash), [hash]);
}

export function navigate(hash: string): void {
  window.location.hash = hash;
```

```ts
    return terms.every((t) => haystack.includes(t));
  });
```

```ts
export interface StreamHandlers {
  onStart(e: StreamStart): void;
  onDelta(text: string): void;
  onDone(e: StreamDone): void;
  onError(e: StreamError): void;
  onTitle(e: StreamTitle): void;
}

/** POSTs to a generation endpoint and dispatches its SSE events. Rejects with AbortError when `signal` aborts. */
export async function streamGeneration(url: string, body: unknown, h: StreamHandlers, signal: AbortSignal): Promise<void> {
  const res = await fetch(url, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(body),
    signal,
  });
  if (!res.ok || !res.body) {
    const data = (await res.json().catch(() => ({}))) as { error?: string };
    h.onError({ message: data.error ?? `Request failed (${res.status})`, partial: null });
    return;
  }
  for await (const ev of parseSSE(res.body)) {
    const data = JSON.parse(ev.data);
    if (ev.event === 'start') h.onStart(data);
    else if (ev.event === 'delta') h.onDelta(data.text);
    else if (ev.event === 'done') h.onDone(data);
    else if (ev.event === 'error') h.onError(data);
    else if (ev.event === 'title') h.onTitle(data);
  }
}
```

```tsx
import { useCallback, useEffect, useState } from 'react';
import type { ChatSummary, LibraryModel, SettingsView } from '../../shared/types';
import { api } from './api';
import { navigate, useRoute } from './lib/route';
import { Sidebar } from './components/Sidebar';
import { ChatView } from './components/ChatView';

import { Settings } from './pages/Settings';

export function App() {
  const route = useRoute();
  const [chats, setChats] = useState<ChatSummary[]>([]);
  const [models, setModels] = useState<LibraryModel[]>([]);
  const [settings, setSettings] = useState<SettingsView | null>(null);
  const [chatReload, setChatReload] = useState(0);
  const [loadError, setLoadError] = useState<string | null>(null);

  const fail = (e: Error) => setLoadError(e.message);
  const refreshChats = useCallback(() => { api.listChats().then(setChats).catch(fail); }, []);
  const refreshModels = useCallback(() => {
    api.listModels().then(setModels).catch(fail);
    api.getSettings().then(setSettings).catch(fail); // default model lives in settings
  }, []);
  const refreshSettings = useCallback(() => { api.getSettings().then(setSettings).catch(fail); }, []);

  useEffect(() => {
    refreshChats();
    refreshModels();
  }, [refreshChats, refreshModels]);

  useEffect(() => {
    document.documentElement.dataset.theme = settings?.theme ?? 'system';
  }, [settings?.theme]);

  const openChat = useCallback((chatId: string) => {
    navigate(`#/chat/${chatId}`);
    setChatReload((n) => n + 1);
  }, []);

  const activeChatId = route.page === 'chat' ? route.chatId : null;
  const title = chats.find((c) => c.id === activeChatId)?.title ?? 'New chat';

  return (
    <div className="app">
      <Sidebar chats={chats} activeChatId={activeChatId} onChatsChanged={refreshChats} onOpenChat={openChat} />
      <main className="main">
        {loadError && <div className="banner error">Can't reach the OpenChat server: {loadError}</div>}
        {route.page === 'chat' && (
          <ChatView chatId={route.chatId} title={title} reloadToken={chatReload} models={models} settings={settings} onChatsChanged={refreshChats} />
        )}
        {route.page === 'models' && <ModelLibrary models={models} onChanged={refreshModels} />}
        {route.page === 'settings' && <Settings models={models} onChanged={refreshSettings} />}
      </main>
    </div>
  );
}
```

```tsx
import { useEffect, useState } from 'react';
import type { ChatSummary, SearchHit } from '../../../shared/types';
import { api } from '../api';
import { groupByDate, splitSnippet } from '../lib/format';
import { navigate } from '../lib/route';

export interface SidebarProps {
  chats: ChatSummary[];
  activeChatId: string | null;
  onChatsChanged(): void;
  onOpenChat(chatId: string): void;
}

export function Sidebar({ chats, activeChatId, onChatsChanged, onOpenChat }: SidebarProps) {
  const [collapsed, setCollapsed] = useState(false);
  const [query, setQuery] = useState('');
  const [hits, setHits] = useState<SearchHit[]>([]);
  const [renaming, setRenaming] = useState<string | null>(null);
  const [draft, setDraft] = useState('');

  useEffect(() => {
    const q = query.trim();
    if (!q) {
      setHits([]);
      return;
    }
    const timer = setTimeout(() => {
      api.search(q).then(setHits).catch(() => setHits([]));
    }, 250);
    return () => clearTimeout(timer);
  }, [query]);

  async function openHit(hit: SearchHit) {
    await api.selectMessage(hit.chatId, hit.messageId).catch(() => {});
    setQuery('');
    onOpenChat(hit.chatId);
  }

  async function commitRename(chat: ChatSummary) {
    if (renaming !== chat.id) return; // Enter and blur can both fire
    setRenaming(null);
    const title = draft.trim();
    if (title && title !== chat.title) {
      await api.renameChat(chat.id, title).catch(() => {});
      onChatsChanged();
    }
  }

  async function remove(chat: ChatSummary) {
    if (!window.confirm(`Delete "${chat.title}"? This cannot be undone.`)) return;
    await api.deleteChat(chat.id).catch(() => {});
    if (chat.id === activeChatId) navigate('#/');
    onChatsChanged();
  }

  if (collapsed) {
    return (
      <aside className="sidebar collapsed">
        <button className="icon" onClick={() => setCollapsed(false)} aria-label="Expand sidebar" title="Expand sidebar">☰</button>
        <button className="icon" onClick={() => navigate('#/')} aria-label="New chat" title="New chat">＋</button>
      </aside>
    );
  }

  return (
    <aside className="sidebar">
      <div className="sidebar-top">
        <span className="brand">OpenChat</span>
        <button className="icon" onClick={() => setCollapsed(true)} aria-label="Collapse sidebar" title="Collapse sidebar">⟨</button>
      </div>
      <button className="new-chat" onClick={() => navigate('#/')}>＋ New chat</button>
      <input className="search" type="search" placeholder="Search chats" value={query} onChange={(e) => setQuery(e.target.value)} />

      <nav className="chat-list">
        {query.trim() ? (
          hits.length ? (
            hits.map((hit) => (
              <button key={hit.messageId} className="hit" onClick={() => openHit(hit)}>
                <div className="hit-title">{hit.chatTitle}</div>
                <div className="hit-snippet">
                  {splitSnippet(hit.snippet).map((part, i) => (part.hit ? <mark key={i}>{part.text}</mark> : <span key={i}>{part.text}</span>))}
                </div>
              </button>
            ))
          ) : (
            <div className="muted pad">No matches</div>
          )
        ) : (
          groupByDate(chats).map((group) => (
            <div key={group.label}>
              <div className="group-label">{group.label}</div>
              {group.items.map((chat) =>
                renaming === chat.id ? (
                  <input
                    key={chat.id}
                    className="rename"
                    autoFocus
                    value={draft}
                    onChange={(e) => setDraft(e.target.value)}
                    onKeyDown={(e) => {
                      if (e.key === 'Enter') commitRename(chat);
                      if (e.key === 'Escape') setRenaming(null);
                    }}
                    onBlur={() => commitRename(chat)}
                  />
                ) : (
                  <div key={chat.id} className={`chat-item${chat.id === activeChatId ? ' active' : ''}`}>
                    <a href={`#/chat/${chat.id}`} title={chat.title}>{chat.title}</a>
                    <span className="chat-actions">
                      <button className="icon" aria-label="Rename chat" title="Rename" onClick={() => { setRenaming(chat.id); setDraft(chat.title); }}>✎</button>
```

```tsx
import { useEffect, useRef, useState } from 'react';
import type { ChatDetail, LibraryModel, SettingsView } from '../../../shared/types';
import { api, streamGeneration } from '../api';
import { formatCost } from '../lib/format';
import { navigate } from '../lib/route';
import { Composer } from './Composer';
import { Markdown } from './Markdown';
import { MessageItem } from './MessageItem';

export interface ChatViewProps {
  chatId: string | null;
  title: string;
  reloadToken: number;
  models: LibraryModel[];
  settings: SettingsView | null;
  onChatsChanged(): void;
}

interface Pending {
  chatId: string;
  /** Number of detail.messages shown above the pending bubbles. */
  baseLength: number;
  /** Optimistic user bubble for send/edit; null for regenerate. */
  userText: string | null;
  replyText: string;
  modelId: string;
}

type RunOptions =
  | { kind: 'send'; text: string; baseLength: number; model: string }
  | { kind: 'regenerate'; parentId: string; baseLength: number; model: string }
  | { kind: 'edit'; messageId: string; text: string; baseLength: number; model: string };

export function ChatView({ chatId, title, reloadToken, models, settings, onChatsChanged }: ChatViewProps) {
  const [detail, setDetail] = useState<ChatDetail | null>(null);
  const [pending, setPending] = useState<Pending | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [modelId, setModelId] = useState('');
  const abortRef = useRef<AbortController | null>(null);
  const viewChatRef = useRef<string | null>(chatId);
  const createdChatRef = useRef<string | null>(null);
  const listRef = useRef<HTMLDivElement>(null);

  const messages = detail?.messages ?? [];
  const streaming = pending !== null;

  async function reload(id: string) {
    const next = await api.getChat(id);
    if (viewChatRef.current === id) setDetail(next);
  }

  // Load the chat whenever the route (or an explicit reload request) changes.
  useEffect(() => {
    viewChatRef.current = chatId;
    if (chatId && chatId === createdChatRef.current) {
      createdChatRef.current = null; // we created this chat for an in-flight send; keep its stream
      return;
    }
    setError(null);
    setPending((p) => (p && p.chatId === chatId ? p : null));
    if (!chatId) {
      setDetail(null);
      return;
    }
    reload(chatId).catch((e: Error) => setError(e.message));
  }, [chatId, reloadToken]);

  // Default model: last model used in this chat, else the current pick, else the library default.
  useEffect(() => {
    const ids = new Set(models.map((m) => m.id));
    const lastUsed = [...messages].reverse().find((m) => m.role === 'assistant' && m.modelId && ids.has(m.modelId))?.modelId;
    setModelId((current) => lastUsed ?? (ids.has(current) ? current : (models.find((m) => m.isDefault) ?? models[0])?.id ?? ''));
  }, [detail, models]);

  // Keep the newest content in view.
  useEffect(() => {
    const el = listRef.current;
    if (el) el.scrollTop = el.scrollHeight;
  }, [detail, pending?.baseLength]);
  useEffect(() => {
    const el = listRef.current;
    if (el && el.scrollHeight - el.scrollTop - el.clientHeight < 160) el.scrollTop = el.scrollHeight;
  }, [pending?.replyText]);

  async function run(opts: RunOptions) {
    setError(null);
    let id = chatId;
    if (!id) {
      try {
        id = (await api.createChat()).id;
      } catch (e) {
        setError((e as Error).message);
        return;
      }
      createdChatRef.current = id;
      viewChatRef.current = id;
      navigate(`#/chat/${id}`);
      onChatsChanged();
    }
    const streamChat = id;
    const isShown = () => viewChatRef.current === streamChat;
    const controller = new AbortController();
    abortRef.current = controller;
    setPending({
      chatId: streamChat,
      baseLength: opts.baseLength,
      userText: opts.kind === 'regenerate' ? null : opts.text,
      replyText: '',
      modelId: opts.model,
    });

    const url = `/api/chats/${streamChat}/${opts.kind === 'send' ? 'messages' : opts.kind}`;
    const body =
      opts.kind === 'send' ? { content: opts.text, modelId: opts.model }
      : opts.kind === 'regenerate' ? { parentId: opts.parentId, modelId: opts.model }
      : { messageId: opts.messageId, content: opts.text, modelId: opts.model };

    const finish = async (message: string | null) => {
      if (isShown()) {
        await reload(streamChat).catch(() => {});
        setPending(null);
        setError(message);
      }
      onChatsChanged();
    };

    try {
      await streamGeneration(url, body, {
        onStart: () => {},
        onDelta: (text) => {
          if (isShown()) setPending((p) => (p && p.chatId === streamChat ? { ...p, replyText: p.replyText + text } : p));
        },
        onDone: () => { void finish(null); },
        onError: (e) => { void finish(e.message); },
        onTitle: () => onChatsChanged(),
      }, controller.signal);
    } catch (e) {
      if ((e as Error).name === 'AbortError') {
        // The server saves the partial reply when it notices the disconnect; give it a moment.
        setTimeout(() => { void finish(null); }, 400);
      } else if (isShown()) {
        setPending(null);
        setError((e as Error).message);
      }
    } finally {
      if (abortRef.current === controller) abortRef.current = null;
    }
  }

  const send = (text: string) => run({ kind: 'send', text, baseLength: messages.length, model: modelId });
  const regenerate = (index: number, model: string) =>
    run({ kind: 'regenerate', parentId: messages[index].parentId!, baseLength: index, model });
  const edit = (index: number, text: string) =>
    run({ kind: 'edit', messageId: messages[index].id, text, baseLength: index, model: modelId });
  const retry = () => {
    const last = messages[messages.length - 1];
    if (!last) return;
    if (last.role === 'user') run({ kind: 'regenerate', parentId: last.id, baseLength: messages.length, model: modelId });
    else run({ kind: 'regenerate', parentId: last.parentId!, baseLength: messages.length - 1, model: modelId });
  };
  const selectSibling = async (messageId: string) => {
    if (!chatId) return;
    try {
      setDetail(await api.selectMessage(chatId, messageId));
    } catch (e) {
      setError((e as Error).message);
    }
  };

  const nameOf = (id: string | null) => models.find((m) => m.id === id)?.displayName ?? id ?? '';
  const shown = pending ? messages.slice(0, pending.baseLength) : messages;
  const noKey = settings !== null && !settings.hasApiKey;
  const noModels = models.length === 0;

  return (
    <div className="chat">
      <header className="chat-header">
        <h1>{chatId ? title : 'New chat'}</h1>
        {detail && detail.chat.totalCost > 0 && <span className="muted small">Total {formatCost(detail.chat.totalCost)}</span>}
      </header>

      <div className="messages" ref={listRef}>
        <div className="messages-inner">
          {(noKey || noModels) && (
            <div className="setup-hint">
              {noKey && <div>Add your OpenRouter API key in <a href="#/settings">Settings</a>.</div>}
              {noModels && <div>Add a model in the <a href="#/models">Model Library</a> to start chatting.</div>}
            </div>
          )}
          {!chatId && !pending && !noKey && !noModels && <div className="empty">How can I help you today?</div>}

          {shown.map((m, i) => (
            <MessageItem
              key={m.id}
              message={m}
              modelName={nameOf(m.modelId)}
              models={models}
              disabled={streaming}
              onSelectSibling={selectSibling}
              onRegenerate={(model) => regenerate(i, model)}
              onEdit={(text) => edit(i, text)}
            />
          ))}

          {pending?.userText != null && (
            <div className="msg user"><div className="bubble">{pending.userText}</div></div>
          )}
          {pending && (
            <div className="msg assistant">
              <div className="msg-body">
                {pending.replyText ? <Markdown text={pending.replyText} /> : <span className="thinking">Thinking…</span>}
              </div>
              <div className="msg-meta"><span className="model-tag">{nameOf(pending.modelId)}</span></div>
            </div>
          )}

          {error && !pending && (
            <div className="error-bubble">
              <span>{error}</span>
              {messages.length > 0 && <button onClick={retry}>Retry</button>}
            </div>
          )}
        </div>
      </div>

      <Composer
        disabled={noModels || noKey}
        streaming={streaming}
        models={models}
        modelId={modelId}
        onModelChange={setModelId}
        onSend={send}
        onStop={() => abortRef.current?.abort()}
      />
    </div>
  );
}
```

```tsx
import { useEffect, useState } from 'react';
import type { LibraryModel, Memory, SettingsUpdate, SettingsView, Theme } from '../../../shared/types';
import { api } from '../api';

export interface SettingsProps {
  models: LibraryModel[];
  onChanged(): void;
}

export function Settings({ models, onChanged }: SettingsProps) {
  const [view, setView] = useState<SettingsView | null>(null);
  const [memories, setMemories] = useState<Memory[]>([]);
  const [keyDraft, setKeyDraft] = useState('');
  const [keyStatus, setKeyStatus] = useState<string | null>(null);
  const [aboutMe, setAboutMe] = useState('');
  const [instructions, setInstructions] = useState('');
  const [savedNote, setSavedNote] = useState('');
  const [newMemory, setNewMemory] = useState('');
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    api.getSettings()
      .then((v) => { setView(v); setAboutMe(v.aboutMe); setInstructions(v.customInstructions); })
      .catch((e: Error) => setError(e.message));
    api.listMemories().then(setMemories).catch((e: Error) => setError(e.message));
  }, []);

  async function update(patch: SettingsUpdate) {
    setError(null);
    try {
      setView(await api.updateSettings(patch));
      onChanged();
      return true;
    } catch (e) {
      setError((e as Error).message);
      return false;
    }
  }

  async function memoryAction(fn: () => Promise<unknown>) {
    setError(null);
    try {
      await fn();
      setMemories(await api.listMemories());
    } catch (e) {
      setError((e as Error).message);
    }
  }

  async function saveKey() {
    if (!keyDraft.trim()) return;
    if (await update({ apiKey: keyDraft })) {
      setKeyDraft('');
      setKeyStatus('Saved.');
    }
  }

  async function testKey() {
    setKeyStatus('Testing…');
    const result = await api.testKey().catch((e: Error) => ({ ok: false, error: e.message }));
    setKeyStatus(result.ok ? 'Connection works.' : `Failed: ${result.error}`);
  }

  async function savePersonalization() {
    if (await update({ aboutMe, customInstructions: instructions })) {
      setSavedNote('Saved.');
      setTimeout(() => setSavedNote(''), 2000);
    }
  }

  if (!view) return <div className="page"><div className="page-inner">{error ? <p className="error-text">{error}</p> : 'Loading…'}</div></div>;

  return (
    <div className="page">
      <div className="page-inner">
        <h1>Settings</h1>
        {error && <p className="error-text">{error}</p>}

        <h2>OpenRouter API key</h2>
        <div className="card">
          <div className="muted small">
            {view.hasApiKey
              ? `Using key ${view.apiKeyMasked} from ${view.apiKeySource === 'env' ? 'the .env file' : 'Settings'}.`
              : 'No key set yet.'}
          </div>
          <div className="row" style={{ justifyContent: 'flex-start' }}>
            <input
              type="password"
              placeholder="sk-or-…"
              value={keyDraft}
              onChange={(e) => setKeyDraft(e.target.value)}
              style={{ flex: 1 }}
              autoComplete="off"
              aria-label="OpenRouter API key"
            />
            <button className="primary" onClick={saveKey} disabled={!keyDraft.trim()}>Save key</button>
            <button onClick={testKey} disabled={!view.hasApiKey}>Test connection</button>
          </div>
          {view.apiKeySource === 'settings' && (
            <div>
              <button className="link danger" onClick={() => update({ apiKey: '' })}>Remove saved key</button>
            </div>
          )}
          {keyStatus && <div className="small">{keyStatus}</div>}
        </div>

        <h2>Personalization</h2>
        <div className="card">
          <label className="field">
            About me
            <textarea rows={4} value={aboutMe} onChange={(e) => setAboutMe(e.target.value)} placeholder="What should models know about you?" />
          </label>
          <label className="field">
            Custom instructions
            <textarea rows={4} value={instructions} onChange={(e) => setInstructions(e.target.value)} placeholder="How should models respond?" />
          </label>
          <div className="row">
            {savedNote && <span className="muted small">{savedNote}</span>}
            <button className="primary" onClick={savePersonalization}>Save</button>
          </div>
        </div>

        <h2>Memory</h2>
        <div className="card">
          <div className="muted small">Enabled memories are added to every chat. Untick a memory to pause it.</div>
          {memories.map((m) => (
            <div key={m.id} className="memory-row">
              <input
                type="checkbox"
                checked={m.enabled}
                onChange={(e) => memoryAction(() => api.updateMemory(m.id, { enabled: e.target.checked }))}
                aria-label="Enabled"
              />
              <input
                type="text"
                defaultValue={m.content}
                onBlur={(e) => {
                  const content = e.target.value.trim();
                  if (content && content !== m.content) memoryAction(() => api.updateMemory(m.id, { content }));
                }}
              />
              <button className="link danger" onClick={() => memoryAction(() => api.deleteMemory(m.id))}>Delete</button>
            </div>
          ))}
          <form
            className="memory-row"
            onSubmit={(e) => {
              e.preventDefault();
              const content = newMemory.trim();
              if (!content) return;
              memoryAction(() => api.addMemory(content)).then(() => setNewMemory(''));
            }}
          >
            <input type="text" placeholder="Add a memory, e.g. “I prefer metric units”" value={newMemory} onChange={(e) => setNewMemory(e.target.value)} />
            <button type="submit" disabled={!newMemory.trim()}>Add</button>
          </form>
        </div>

        <h2>Other</h2>
        <div className="card">
          <label className="field">
            Model for chat titles
            <select value={view.titleModelId} onChange={(e) => update({ titleModelId: e.target.value })}>
              <option value="">Same model as the chat</option>
              {models.map((m) => <option key={m.id} value={m.id}>{m.displayName}</option>)}
            </select>
          </label>
          <label className="field">
            Theme
            <select value={view.theme} onChange={(e) => update({ theme: e.target.value as Theme })}>
              <option value="system">System</option>
              <option value="light">Light</option>
              <option value="dark">Dark</option>
            </select>
          </label>
        </div>
      </div>
    </div>
  );
}
```

````markdown
# OpenChat

A local, single-user chat app in the style of Claude.ai that talks to any model on [OpenRouter](https://openrouter.ai).

## Setup

```bash
npm install
```

Add your OpenRouter key either in the app (Settings → OpenRouter API key) or in a `.env` file:

```bash
cp .env.example .env
```

## Run

```bash
npm start
```

Open http://127.0.0.1:3000. For development with hot reload use `npm run dev` and open http://localhost:5173.

## Use

1. **Model Library** → search the OpenRouter catalog → **Add** the models you want.
2. Start a chat; switch models from the picker any time.
3. **Regenerate** any reply with any model, or **Edit** your message — every version is kept; flip with ‹ ›.
4. **Settings** → About me, custom instructions and memories are added to every chat.

Data lives in `data/openchat.db` (SQLite). Delete it to start fresh.

## Scripts

- `npm test` — server and helper tests (Vitest)
- `npm run typecheck` — TypeScript
````
